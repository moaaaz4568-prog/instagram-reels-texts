So my experiments on Amazon got me thinking, can I create a keyword-embedded super URL for eBay? If you run a search on eBay, the search page comes back with a URL that has all kinds of crazy parameters, none of which I really know what they mean. But if you click on a listing, there are no keywords in the URL. There's no way to associate a keyword with this listing. However, if you go to a seller's storefront, you can actually run a search and then you end up with a storefront URL that has a keyword embedded in it, as well as a couple of other parameters. I haven't figured out what they mean yet, but that could be helpful. If I were to run a promotion strategy with coupons, if they're available, or with rebates, this is the URL that I would test.
