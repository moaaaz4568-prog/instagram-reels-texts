What is the difference between ridge regression and lasso regression? Penalty term: Ridge regression adds the L2 norm of the coefficients to the cost function, while lasso regression adds the L1 norm. L2 norm penalizes the sum of the squared coefficients, while L1 norm penalizes the sum of the absolute values of the coefficients. Selection of features: Ridge regression shrinks the coefficients towards zero, but it doesn't set any coefficients exactly to zero, meaning that all features are retained in the model. Lasso regression can set some coefficients to exactly zero, resulting in feature selection and a simpler model.
