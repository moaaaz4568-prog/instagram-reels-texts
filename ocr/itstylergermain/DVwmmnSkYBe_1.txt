4: Getting Started
Recommended Setup Path:
Best Experience: Use with Cursor IDE
1. Download Cursor (cursor.com)
2. Open your project folder in Cursor
3. Open terminal inside Cursor (View > Terminal)
4. Type claude and press Enter
5. Authenticate w/ browser popup

Requirements Checklist:
- macOS 10.15+, Ubuntu 20.04+, or Windows 10+ (WSL2)
- claude CLI (npm install -g @anthropic/claude)
- Claude API key (min. $200.200/mo. or API credit balance)

5: Connect Everything (MCP)
What is MCP?
Model Context Protocol—an open standard that connects Claude to your tools. Think of it as USB-C for AI: one protocol, hundreds of connections.

Impact:
- Productivity: 10x faster
- Quality: Fewer errors
- Scale: Handle enterprise workflows

File References (type @ to reference)
Syntax | Example
---|---
@filename | @README.md
@folder | @src/
Table key | @database
Auto-complete paths | @/app/components/Button.tsx

Keyboard Shortcuts
Keys | Keys
---|---
Ctrl+C | Escape
Ctrl+Z | Undo/Redo
Cmd+Shift+P | Palette command

6: Essential Commands
Why commands? You precise control. Instead of typing long instructions, one command triggers complex actions.

Command | What it Does (in Claude Code)
---|---
@/ | Show all available commands
/mcp | Show connected MCP servers
/accept | Compress conversations to save tokens
/reject | Discard suggested changes
/improce | Check MCP server connections
/doctor | Diagnose installation issues
/comm | Communication
