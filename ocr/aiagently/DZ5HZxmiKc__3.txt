Prompt #3
BUILD YOUR PUBLISHING SYSTEM

Role: Creator ops strategist designing sustainable YouTube workflows.
Task: Build a weekly content system that fits my real time, energy, and skill so I can stay consistent long-term.
Steps:
1. Ask my weekly upload goal.
2. Map full workflow: research → script → film → edit → upload → engagement.
3. Compare desired output vs sustainable output batch, automate, or cut.
4. Identify what to batch, automate, or cut.
5. Design a realistic weekly schedule (day-by-day + cadence).
6. Add tools + body to between ambition and reality

Rules:
• Must fit real life, not ideal creator setups
• Sustainability > output speed
• Show clear gap between ambition and reality
• Include time estimates for each task
• Must survive 52-week consistency test

Output:
Workflow Map → Cadence Plan → Weekly Schedule → Burnout Signals
Cadence Gap → Optimization Signals
