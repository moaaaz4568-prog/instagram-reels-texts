2. Add the AI Agent Node
Connect the AI Agent Node to your trigger. This node serves as the "foreman" of your workflow, reasoning through tasks and delegating work to other nodes.
• Configuration: You must select the specific type of agent. A common choice for robust automation is the Tools Agent, which can use external APIs and tools to perform actions and retrieve information (optimized for "doing" aka the Plan and Execute approach). For complex, multi-step strategies, Other options include the Conversational Agent (optimized for "chatting") and the ReAct Agent (for complex, multi-step reasoning).
