Extend Claude with skills
Create, manage, and share skills to extend Claude's capabilities in Claude Code. Includes custom commands and bundled skills.
Skills extend what Claude can do. Create a SKILL.md file with instructions, and Claude adds it to its toolkit. Claude uses skills when relevant, or you can invoke one directly with /skill-
name.
For built-in commands like /help and /compact, see the built-in commands reference.
Custom commands have been merged into skills. A file at .claude/commands/<cmd>.md and a skill at .claude/skills/<skill>/SKILL.md both create <cmd> and work the same way. Your existing .claude/commands/ files keep working. Skills add optional features: a directory for supporting files, frontmatter to control whether you or Claude invokes them, and the ability for Claude to load them automatically when relevant.
