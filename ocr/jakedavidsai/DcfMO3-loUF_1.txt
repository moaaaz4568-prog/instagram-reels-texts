The agent receives messages,
decides which tool to use (if any), and formulates
a response with the full example personality and
instruction
It uses Google Gemini to power its reasoning and
retrieval (searches, etc.)
Comes pre-equipped with two tools: Get Weather
(fetches real-time weather) and fetch news feeds
(aan RSS feed for latest headlines)
Conversation memory notes allow the agent to
remember past messages, enabling natural
follow-up conversations

2 SETUP STEPS – GET STARTED IN 2 MINUTES

a free Google AI API key

On the workflow canvas, go to the
Chat Agent node. Select the

select your API key.
Paste your API key into the API key
field and click Save
Go to the Customize node and
the "Open Chat" button in its
parameter panel
Try asking example questions like:
"what's the weather in Paris?"
or "Get me the latest tech news"
You now have a fully functional
AI agent who can fetch news (using
Google Calendar to make it even
more powerful)
