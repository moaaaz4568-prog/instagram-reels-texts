MCP Core Components
At is core, MCP follows a client- server architecture where a host application can connect to multiple servers:
Host Application
LLMs that interact with users and initiate connections. This includes Claude Desktop, Cursor etc.
MCP Server
Adds context and capabilities, exposing specific functions to apps through MCP.
MCP Client
Handle connections with MCP servers, translating between the host's requirements and the MCP.
All communication in MCP uses JSON-RPC 2.0 as the underlying message standard.
